Where to list an MCP server, in order

01

Official MCP Registry

For an npm package, add mcpName to package.json and publish it, then run mcp-publisher init, login and publish. MCPfinder reads from it, and PulseMCP says it will once it reopens.

02

Glama

Use “Add Server” on glama.ai/mcp/servers. MCPfinder indexes Glama too.

03

Browsing directories

Add the server to directories people browse, such as mcp.so (free with review). Keep the description and install command the same everywhere.

FAQ

Common questions

Where should I list a new MCP server first?
Publish it to the Official MCP Registry with the mcp-publisher CLI. The registry hosts metadata only: for an npm package, add mcpName to package.json and publish it (other package types such as PyPI or OCI use their own verification), then run mcp-publisher init, login and publish. Remote-only servers can be registered with a remotes entry in server.json instead. PulseMCP’s submit page also points to the Official MCP Registry and says it will pick servers up from there once it is back, and MCPfinder indexes it.
Is the Official MCP Registry ready for production?
Its documentation says the registry is in preview, and breaking changes or data resets may occur before general availability (modelcontextprotocol.io, checked 4 November 2026).
Can I still submit a server to PulseMCP?
Not right now. PulseMCP’s submit page says new server and client submissions and listing changes are paused (last updated 3 September 2026) and points developers to the Official MCP Registry, which it says it will pick up once submissions resume.
Is listing on mcp.so free?
mcp.so offers a free submission that goes through review, and a paid option for a one-time fee of $39 that publishes immediately without review (mcp.so/submit, checked 4 November 2026).
Does Smithery still work as a directory?
smithery.ai stays online as a public, non-proxied directory, now powered by Arcade.dev. Smithery said its MCP proxy, server URLs, CLI and SDKs would stop working on 31 October 2026 (smithery.ai/future).
How do I get my server into MCPfinder?
There is no separate submission. MCPfinder builds its index from the Official MCP Registry and Glama. New index snapshots are built several times a day, but Glama data comes from a capture taken about once a day, so a new Glama listing can take a day or two to appear.
