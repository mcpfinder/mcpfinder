How it works

Three tool calls between “I need X” and a working server.

You install MCPfinder once. After that, your agent uses it on its own whenever a request needs a tool it doesn't have.

  1. 01search_mcp_servers

    Search the merged index

    Matches by keyword, technology or use case across both registries, deduplicated. Every result says why it ranked and what looks off.

    confidenceScore: 0.55
sources: ["official"]
warningFlags: ["single-source-only", "missing-repository-url"]
  2. 02get_server_details

    Check before recommending

    Transport, required environment variables or HTTP headers, last update, repository, and the tools the server exposes — so the agent can explain the trade-offs instead of guessing.

    installComplexity: "low"
secretCount: 0
freshnessDays: 23
  3. 03get_install_config

    Write the exact config

    JSON for your client, the file it belongs in, which secrets you need to fill in, and whether to restart.

    configFilePath: { mac: "~/.cursor/mcp.json", … }
requires_user_secrets: false

Only know the domain, not the product? browse_categories lists categories like database, filesystem, communication and security with the top servers in each.

What it checks

It tells your agent when to hesitate.

Registries list everything: abandoned forks, placeholder entries, look-alikes of official servers. MCPfinder scores every candidate and returns the reasons, so your agent can repeat them to you instead of installing blind.

Scores

confidenceScore
0 to 1. Built from official-registry presence, how many registries list the server, metadata completeness and freshness. Higher means more evidence it is real and installable.
installComplexity
low: runs via npx, uvx or Docker with at most one non-secret setting. medium: a few settings, some secret. high: many secrets or no clean install path.
requires_user_secrets
Whether you must supply API keys or tokens. MCPfinder separates local environment variables from remote HTTP headers and lists optional ones separately.

Warning flags

single-source-only
Listed in only one registry.
missing-repository-url
No public source code link.
missing-update-date
No reliable last-updated date.
install-method-unclear
No package or URL MCPfinder can turn into config.
stale-over-12-months
stale-over-18-months
Not updated in over a year (or 18 months).
archived-repo
The source repository is archived.
repo-unavailable
The source repository is not publicly reachable (private or deleted).
deprecated-npm
The npm package is marked deprecated. The largest score penalty.
status:<value>
The registry marks the server with a non-active status, e.g. deprecated.

Install

Install in under a minute.

MCPfinder runs locally as a stdio MCP server through npx. Pick your client, add the snippet, restart if asked.

Claude Desktop

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "mcpfinder": {
      "command": "npx",
      "args": ["-y", "@mcpfinder/server"]
    }
  }
}

Restart Claude Desktop. On Windows the file is %APPDATA%\Claude\claude_desktop_config.json.

Claude Code

terminal
$ claude mcp add mcpfinder -- npx -y @mcpfinder/server

Or add the same mcpServers block to .mcp.json in your project.

Cursor

~/.cursor/mcp.json
{
  "mcpServers": {
    "mcpfinder": {

    }
  }
}

Use .cursor/mcp.json for a single project. Cursor picks up the change without a restart.

VS Code

      "type": "stdio",

  }

Reload the window, then enable the server in Copilot Chat's tools picker.

Data

Where the servers come from.

MCPfinder merges the Official MCP Registry and Glama into one deduplicated SQLite index and ships it as a published snapshot. The local server downloads that snapshot, then answers your agent's searches from the local copy.

FAQ

Questions

What is MCPfinder?

MCPfinder is a free, open-source MCP server that helps AI agents discover, evaluate and install other MCP servers. It searches the Official MCP Registry and Glama, returns trust signals and warning flags for each candidate, and generates install config for Claude Desktop, Claude Code, Cursor, Windsurf and Cline in VS Code.

What is an MCP server?

The Model Context Protocol (MCP) is an open standard, introduced by Anthropic, that lets AI applications connect to external tools and data. An MCP server exposes tools, resources or prompts — for example a database, GitHub, Slack or a browser — that an MCP client like Claude Desktop or Cursor can use.

How do I find the right MCP server for a task?

Install MCPfinder and ask your agent for the capability in plain words. It calls search_mcp_servers, inspects the best candidates with get_server_details, and uses get_install_config to produce the config. You get a recommendation with reasons and warnings, not just a list of links.

Is MCPfinder free? Does it need an API key?

Yes, it is free and open source under AGPL-3.0. It needs no account and no API key; it runs locally through npx -y @mcpfinder/server.

Can I use it at work or in a commercial product?

Yes. You can run it and use it with your agents in any personal, internal or commercial setting. AGPL-3.0 only requires that if you modify MCPfinder and offer it as a network service, you publish those changes under the same licence. For other licensing, contact Coder AI.

Does MCPfinder install servers by itself?

No. It only returns the config and tells your agent which secrets are needed and what to restart. Your agent or you apply the change, so nothing is added to your client without you seeing it.

Which registries does it search, and how fresh is the data?

The Official MCP Registry and Glama, merged and deduplicated. The data ships as a published snapshot; its publish date and server count are public at /api/v1/snapshot/manifest.json. Each result also carries its own updatedAt and freshness flags such as stale-over-12-months.

Is there a hosted HTTP endpoint?

Not yet. The local stdio server is the supported interface. A hosted endpoint with the same tools is on the roadmap.

How can I contribute?

Issues and pull requests are welcome on GitHub at github.com/mcpfinder/mcpfinder. The project is maintained by Coder AI.
